# Mun River Power release

The latest local package is `MunRiverPower-0.17.6.zip`. Close Cities: Skylines II, extract the ZIP, and run `MunRiverPower/Install.cmd` to install it.

Build output and older release archives are excluded from Git. The latest ZIP is kept in this repository for direct testing. Source code is in `src/`; model source and exports are in `assets/ModernDam/`.
